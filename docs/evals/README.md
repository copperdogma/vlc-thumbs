# Evals

`registry.yaml` is authored truth. Root contract exists; product execution is
deferred until a pinned VLC build and legal fixture exist. `make validate` checks
methodology/skill integrity only. It does not run this eval.

Use `/create-eval` for new contracts and `/improve-eval` for measured failures.
Prefer macOS UI evidence, deterministic storage checks and media/frame comparisons.
PromptFoo/model discovery is dormant: there is no product AI requirement.
Each attempt records revision, OS/build, source and fixture hashes, commands,
thresholds, exact tested interactions, results and unresolved scope. Use the
attempt template; failures are not fabricated to justify decomposition.
