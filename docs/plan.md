# Initial plan

1. Establish feasibility: inspect primary VLC documentation and pinned macOS
   source, inventory normal/fullscreen timeline controls, compare extension/module/
   UI-patch routes, and establish a reproducible build and legal fixture path.
2. Use that evidence to choose a small integrated preview/annotation vertical
   slice. Set latency, correspondence, storage and playback acceptance thresholds
   before implementation. Keep user-facing controls in the same story.
3. Run the root scenario with restart persistence and source-media integrity.
   Broaden formats, durations, fullscreen and failure cases according to evidence.
4. Decide packaging, move/rename identity, colors/tags and upstream contribution
   only when the initial experience works.

This is provisional. Story 001 is Draft because the source/build/UI substrate is
unverified. Setup is complete when its checks pass; product feasibility and
implementation remain future work. No prior Ultima/BGI results apply to VLC.
