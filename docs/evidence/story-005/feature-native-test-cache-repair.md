# Normal macOS test configuration cache

The actual real-controller race test initially aborted in normal controller teardown: `resumeOtherAudioPlaybackApps` inherited `macosx-control-itunes`, absent from the old build-tree plugin cache. No synthetic variable or configuration registration was introduced. The repaired test requires that real descriptor before allocating the controller and disables scanning, so XCTest does not load duplicate GUI Objective-C classes.

Apple's [SIP runtime protections guide](https://developer.apple.com/library/archive/documentation/Security/Conceptual/System_Integrity_Protection_Guide/RuntimeProtections/RuntimeProtections.html) documents purging dyld environment variables when protected processes launch. The libtool cache-generator wrapper starts `/bin/sh`; a sanitized local `/bin/sh` probe lost `DYLD_FRAMEWORK_PATH`. The wrapper invocation failed to acquire the GUI descriptor; direct invocation of the actual uninstalled Mach-O with scoped own-core and configured contrib framework paths succeeded. Receipts: `reproduction-cachegen-20261006T061202Z.json` (wrapper, descriptor absent), `reproduction-cachegen-20261006T061330Z.json` (Mach-O, descriptor present). This is loader/setup behavior, not a missing product option or packaged-app requirement.

The normal macOS test build list now makes all registered XCTest bundles depend on a build-tree cache preparation target. It first builds the normal GUI plugin and cache generator, then directly invokes the uninstalled generator with configure-derived library/framework paths. Automake checks, full `check-macosx`, and focused selector checks receive the same build-tree `VLC_PLUGIN_PATH`. The focused real-controller check uses cached configuration and no plugin scanning. No system security settings, installed apps, or baseline files are changed.

Applicability remains native macOS Autotools builds with dynamic plugins; the test setup is conditional on existing native macOS XCTest enablement. Other platforms and Meson test execution are not qualified by this repair.
