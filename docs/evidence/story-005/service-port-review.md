Earlier cache diagnostics also exposed a test setup issue: macOS temporary paths can begin `/var`, a symlink rejected by the existing safe-cache ancestry policy. Local applicability was verified by cache and service persistence tests, rather than weakening symlink rejection.

The normal build and source hashes are distinct from earlier prototype binaries. ## Independent-review repairs

`service-port-repair-receipt.json` supersedes the initial source hashes. Review identified a blocking command-pipe write and malformed-input validation gaps. The worker now sets its command descriptor nonblocking, advances through partial writes, retries EINTR, waits for EAGAIN/EWOULDBLOCK with bounded poll intervals, rejects POLLERR/POLLHUP/POLLNVAL and checks the cancellation epoch. The fixed request deadline is established before writing and passed unchanged to the reply reader; write progress cannot renew it. Failure closes/retire-bounds the worker. This follows [POSIX write](https://pubs.opengroup.org/onlinepubs/9690949599/functions/write.html) and [POSIX poll](https://pubs.opengroup.org/onlinepubs/9799919799/functions/poll.html). A real-pipe XCTest fills a pipe before a short deadline, cancels while it is full, closes the reader, and transfers a 256 KiB patterned buffer through a deliberately slow drain. It passes in 0.579 seconds and verifies the received bytes, rather than assuming one write completes a command. This is IPC contract hardening; no normal-protocol backpressure hang is claimed to have been observed.

Service contexts now require true CFBoolean eligibility and a nonboolean, integral sourceEpoch in the NSUInteger range. Generation remains the presentation identity. Tests reject missing epoch, malformed eligibility/epoch and numeric eligibility. Cache and service compare the validated raw channel NSNumber exactly to four, preventing a large value such as 4294967300 from being truncated by intValue; cache and injected helper regressions reject that payload before image construction.

The subsequently selected flat-Matroska admission contract changes mapping to `matroska-track-number-flat-v1` and cache namespace to `v5:keyframe-master-id1:transform1:flat-mkv1`. Protocol remains 4. Old uncertified Matroska mapping is explicitly rejected; non-Matroska single mapping is unchanged. Admission itself belongs to the production helper lane.

Focused diagnostic cache, command-pipe, channel overflow, malformed-context and selection tests pass. Logs are enumerated in the repair receipt. Compilation uses actual candidate XCTest source; the build owner is running the corresponding narrowed normal-target round. These tests do not replace production decoding or native interaction gates.
